# Screenshot capture checklist

Screenshots must come from the running application with a development Firebase project. None are currently presented as verified in the README. The cloud review can build the client, but access to the Firebase JavaScript CDN/backend is restricted and no authenticated workflow has been demonstrated.

Please capture these screens, preferably at the same phone resolution:

| File to add under `docs/screenshots/` | Screen and required state |
| --- | --- |
| `registration.png` | Registration form, no password or personal email visible |
| `jobs.png` | Actual development listings with title, city and payment; show a successful filter if possible |
| `create-job.png` | Employer's job form with title, type, requirements, payment and headcount |
| `profile.png` | Profile with role/city; use an account you control and anonymize private details |
| `chat.png` | A conversation between two development accounts, with message order/read state visible |

Use data entered through real application flows. Label it as development/test data in the caption. For chat, include only messages you are authorized to share. Crop unrelated browser chrome if helpful; do not alter the application UI or fabricate success states.

Alongside the images, record platform, Flutter version and which scenarios were verified. If a screen fails to load, report that failure instead of replacing it with a mockup. Add images to the README only after those files exist and have been reviewed.
